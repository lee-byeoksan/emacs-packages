# diff 리뷰 의견

`eam-review-selection` / `C-c a v`는 선택한 diff와 의견을 대상 세션의 편집 초안에 추가한다. CLI 시작·제출·AI 호출은 하지 않는다. 명시적인 선택 영역과 사용자 의견만 전달하며 시스템 프롬프트나 자동 컨텍스트를 추가하지 않는다.

`lisp/eam-review.el`은 unified diff hunk에서 변경 전·후 줄 범위를 계산한다. 삭제 줄의 새 위치는 none으로 표시한다. 여러 파일·hunk, 한글·공백 파일명, Git의 인용/8진수 UTF-8 경로를 처리한다. 선택 내용에 코드 펜스가 있으면 더 긴 펜스를 사용한다. 기본 선택 상한은 12,000자다.

의견과 대상 선택이 끝나기 전에는 초안을 생성하거나 변경하지 않는다. 기존 내용 뒤에 추가하고 undo 경계를 유지한다. 취소하면 기존 초안이 유지된다.

Magit에서는 현재 파일명만으로 이전 경로를 추정하지 않고 원래 diff 헤더를 읽는다. 이름 변경 시 이전 경로가 새 경로로 바뀌던 오류를 이 방식으로 해결했다. 접힌 영역은 펼친 후 재선택하도록 안내하며 보이지 않는 텍스트를 포함하지 않는다.

일반 unified diff가 대상이고 combined/binary diff는 지원하지 않는다. 줄 위치는 diff 생성 시점 기준이며 현재 파일 위치와 다를 수 있다. `tests/review-test.el`, `tests/review-magit-test.el`이 변경 위치·경로·한도·취소·undo·무전송을 검사한다. 과거 Magit 4.4.0 배치 검증과 일반 GUI 영문 의견/undo 관찰이 있었으며, 이것을 모든 Magit 버전·물리 한글 입력 검증으로 확대하지 않는다.
